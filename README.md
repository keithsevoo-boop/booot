# AetherMind — Next-Generation AI Companion

**AetherMind** is a visionary, investor-ready AI assistant platform prototype.  
It features a stunning modern graphical interface, real-time chat, multi-modal capabilities, task automation, and seamless online connectivity — all without relying on external paid LLM APIs for the core demo experience.

Built as a Progressive Web App (PWA), it works on desktop, mobile, and can be installed on phones like a native app. It automatically connects to the internet when available and gracefully handles offline mode.

> **Vision**: An intelligent agent that lives on your device, understands context, executes tasks, and feels like a true digital companion — designed to attract sponsors, investors, and early adopters.

## 🚀 Quick Start

1. Clone this repository
2. Open `index.html` in a modern browser **or**
3. Serve it locally:
   ```bash
   npx serve .
   # or
   python -m http.server 8000
   ```
4. For full PWA experience, serve over HTTPS (or use localhost)

No build step required. Pure HTML + CSS + Vanilla JS for maximum simplicity and transparency.

## 🛠 Tech Stack

- **Frontend**: HTML5, CSS3 (Glassmorphism + CSS Variables), Vanilla JavaScript
- **PWA**: Service Worker, Web App Manifest
- **APIs used (all free / native)**:
  - Web Speech API (speech recognition & synthesis)
  - LocalStorage / IndexedDB ready
  - Network Information API
  - MediaDevices (camera/mic preview)
- **No external paid LLM APIs** in the core experience — responses are generated by a sophisticated rule + pattern engine that can later be swapped for real models.
